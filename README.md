# DrumDrill 爵士鼓檢定特訓

照 [PianoDrill](https://github.com/stevenmusic/PianoDrill) 的版面做的爵士鼓練習 App(網頁版 + iOS App)。

- **技巧**:國際打擊樂協會(PAS)40 個國際標準基本打法,照官方表重新繪製鼓譜、每個音標左右手;
  真實鼓聲示範(Naked Drums 取樣)、預備拍、速度 30–240、循環與每輪加速、練過的最快速度、練習紀錄
- **視奏、聽力**:準備中(照 Trinity / RSL 官方大綱整理後才做)
- **檢定**:Trinity Rock & Pop Drums、RSL Rockschool Drums(初級/入門 – 8 級)

沒有 build step:直接用瀏覽器打開 `index.html`(要用本機伺服器,例如 `python3 -m http.server`)。
