# 出題器(產生器)設計說明

> 這份寫的是 App 自己的出題設計(不是官方內容):§1 Trinity Playback、§2 RSL 整組鼓視奏、§3 RSL 聽力、§4 共用的播放事件、§5 RSL 的測試。官方要求一律來自 `data/exam-*.json`(逐項有頁碼,`docs/sources/*.md` 逐頁核對過);
> 這裡的「拍型、組合方式、機率」都是 **練習設定**,大綱沒寫、App 先這樣解讀的是 **推估**。

## 1. Trinity Rock & Pop Playback 譜(`js/shared/playbackgen.js`;STAGES.md S10 + S11)

### 1.1 介面

- `genChart(params, seed)` → `{ grade, seed, time, times, phrases:[{ bars, start, time, measures, dyn }], dyn, totalBars, spec, notes, src }`
  - `params` = `playbackFor(g, data)`(`js/shared/examdata.js`,累積白名單);`playbackParams(g, data)` = 同一份再加上 `fresh`(這一級新增的項目,出題時加重 3 倍)。
  - `spec` 直接給 `kitnotation.js` 的 `scoreXML`(五線、手 / 腳兩個聲部;沒有大鼓、腳踩 HH 的題目只有手的聲部)。
  - `phraseSpec(chart, i)`:一句單獨的譜(聽力「聽句回打」用)。這一句開頭沒寫力度的話(1 級起),補上整份譜在這一句開頭以前最後一個力度記號
    (p mp mf f pp ff;不含漸強漸弱、sfz),所以單獨看也知道多大聲;sfz 不放在句子的第一拍(避免跟補上的力度疊在同一個位置)。
  - `notes`:說明 key,文字在 `NOTES[key].text`(`[中, 英]`)、`kind` = `assumed`(推估)/ `practice`(練習設定)/ `omit`(不出的項目)。
  - 同一個 `params` + 同一個 `seed` → 同一題(mulberry32)。速度不在產生器裡(官方沒寫;視奏 / 聽力介面自己標「練習設定」)。
- 純函式:不碰 DOM、不 import i18n,Node 可以直接跑。
- 播放:題目的 `spec` 交給共用的 `kitevents.toEvents`(§4)。視奏分頁的「Playback 看譜練習」(`js/sight/app.js`,S9 接上;速度預設 ♩=80 = 練習設定)已經這樣用;聽力的「聽句回打」在 S13。

### 1.3 不出的東西

- **滾奏、Ruff**:大綱只寫名稱,沒寫是哪一種、怎麼寫(NOTES.noRollRuff)。
- **Ride bell**:大綱「全套鼓」沒列鼓件(NOTES.fullKit);drumkey 有菱形符頭(Trinity 勘誤),但 Playback 不用。
- `docs/NOTATION.md`「做不到」的記號:分組拍號分子(7/8 只印 7/8,照 2+2+3 連桿)、一小節反覆 %、choke、半開 HH、rim-shot。
- 速度:官方沒寫。

### 1.4 出題設計(練習設定)

- **一句** = 律動小節 + 最後一小節過門(整小節,或一半機會後半小節)。下一句開頭常有 Crash(過門的落點;Initial 是單獨一個 Crash)。
- **收尾**:最後一句 55% 機會用 Crash(+ 大鼓)長音收尾(四分、二分、附點二分、全音符、附點四分,照白名單與拍號);整小節的長音前一小節是過門。
- **組 = 拍**:x/4、x/2 每個四分音符;6/8、9/8、12/8、3/8 每個附點四分;5/8 = 3+2、7/8 = 2+2+3 個八分音符(`kitnotation.parseTime` 的分組;NOTES.compound)。
  每一組從節奏格挑一格(`CELL_Q` 一拍、`CELL_QM` 跨拍、`CELL_DQ` 附點四分、`CELL_DQM` 附點二分),格子裡每個時值與休止符都要在白名單裡。
  三連音、六連音、四分三連音只在 x/4、x/2;二連音只在 6/8、9/8、12/8、3/8。
- **律動**(2 級起):鈸(HH 或 Ride,一句固定)用 `OST_Q` / `OST_DQ`;反拍(單數的組;3/8 是單數的小節;2/2 半小節一拍,只有第 3 個四分音符)加小鼓或 rim-click;
  2/2 拍與拍之間的四分音符(第 2、4 個)大鼓少一點(35%,其他拍 85%);
  大鼓從 `KICK_Q` / `KICK_DQ` 挑(2 級以前只有拍點上的四分 / 附點四分),同一句的律動小節大致重複(每組 30% 換)。
- **過門**:小鼓 → 高 → 中 → 落地鼓(偶爾往上),每組一個鼓,四個音以上的組有時候分兩個鼓;腳有時候加大鼓,或整段用腳踩 HH 打拍子。
- **聲部數** = 同一個時間點同時打的肢體數(和弦的音 + 腳;Flam / Drag 多算一隻手;連結線接續的音不算)(推估,NOTES.voices)。
  「部分 2 聲部」= 至少一小節、最多一半的小節;「大多 2 聲部」= 超過一半的小節;3 聲部 = 最多 3 個、每題至少一個。手打 HH 與腳踩 HH 不同時。
- **休止符**:沒有打的聲部寫整拍休止(四分、附點四分),能合就合成二分(4/4、2/2 第 1、3 拍起;3/4 第 1 拍起)或附點二分(複拍子兩組);
  整小節都沒有打:3 級起寫整小節休止(全休止符);Initial–2 級還沒有全休止符,腳整小節沒有打就不印休止符
  (`kitnotation` 的 `hideEmpty` → `<note print-object="no">`,時值照算、不畫;不會用到白名單以外的記號)。手的聲部不會整小節空白。
- **連結線**(2 級起):一句 45% 機會加 1–2 條,只接過門(單線)裡「跨拍」的音:前一個音八分音符以上、結束在拍點(組的開頭或小節線;可以跨小節線,不跨句子),
  接到同一個鼓件、下面沒有腳的下一個音;同一拍內的短音不連(那種寫法讀起來像錯字,也不是爵士鼓譜常見的連法)。
- **換拍號**(8 級):每題換 1–2 次(60% 一次、40% 兩次;最多 3 種拍號),只在句子之間。新的拍號照「相近」加重 ×6(`REL_TIME`):
  分母一樣(x/4 ↔ x/4、x/8 ↔ x/8),加上 2/2 ↔ 4/4、2/2 ↔ 2/4、4/4 ↔ 12/8、4/4 ↔ 6/8、2/4 ↔ 6/8、3/4 ↔ 6/8、3/4 ↔ 9/8;其他的拍號也可能,但機會小很多。
- **力度**:第一句開頭一定寫;之後每句 55% 換一個(換了才寫);換的時候 70% 在上一句的過門加漸強 / 漸弱(方向要對);sfz 一題最多一個。
- **開 HH**:HH 律動 60% 的句子會用,每小節 40% 機會開一次,下一個 HH 寫閉(+)。
- **長度**:總長在範圍內隨機;60% 每句一樣長(整除時),不然隨機切(每種切法機會一樣),每句都在句長範圍內。
- **新元素加重**:`fresh`(這一級新增的拍號、時值、力度、鼓件)出現的機會 ×3。

### 1.5 推估(畫面要標「推估 / Assumed」)

| 項目 | 解讀 |
|---|---|
| 總長度不含回打的小節 | 譜上每一句只寫一次,回打由播放器處理(NOTES.totalExcludesRepeat) |
| 換拍號的位置 | 只在句子之間(NOTES.meterChange) |
| 聲部數的意思 | 同時打的肢體數;「部分 / 大多」照上面的比例(NOTES.voices) |
| LT = 落地鼓 | 資料檔 `playback.pieceMap.LT`(NOTES.lowTom) |
| 全套鼓的鼓件 | SD、BD、三個筒鼓、HH、Ride、Crash、rim-click(NOTES.fullKit) |
| 5/8、7/8 的分組 | 3+2、2+2+3(常見寫法,待核對;NOTES.compound) |
| 2/2 的律動 | 半小節一拍:小鼓(rim-click)反拍只在第 3 個四分音符(NOTES.cutTime) |
| rim-click | 用 drumkey 的 cross stick(xstick)符號與聲音(NOTES.rimClick) |
| Initial「只有單線」| 一次只打一個:手腳輪流、不同時(NOTES.singleLine) |

## 2. RSL 4–5 級整組鼓視奏(`js/shared/kitgen.js`;STAGES.md S9)

### 2.1 介面

- `genRslKit(spec, seed, grade)` → `{ grade, seed, time, bars, bpm, bpmRange, develop:{ from, bars }, cyms, spec, measures, events, lenBeats, notes, src }`
  - `spec` = `data/exam-rsl.json` 的 `sight[4]` / `sight[5]`(`type:"kit"`;小鼓視奏的參數會丟錯);同一個 spec + seed → 同一題(mulberry32,跟 playbackgen 同一個寫法)。
  - 輸出的 `spec` 直接給 `kitnotation.scoreXML`(五線、手 / 腳兩個聲部);自由發展的小節是 `{ slash:true }`(每拍一個斜線符頭)。
  - `events` = `kitevents.toEvents(spec, { bpm })`;自由發展的小節不出聲(播放器只打拍點)。
  - `notes`:說明 key,文字在 `NOTES[key].text`,`kind` = `assumed` / `practice`(同 Playback)。
- 也匯出 `maskVoice`(一拍 = 四個十六分格子 → 寫法)、`rng` / `wpick` / `randInt`(聽力的 Groove 共用)。

### 2.3 出題設計(練習設定)

- **段落**:前段第 1–4 小節(律動,第 4 小節末過門)、後段第 5–6 小節(第 5 小節第 1 拍 Crash,第 6 小節末過門接自由發展)、第 7–8 小節自由發展。
- **手**:鈸一段固定(前段 70% HH;後段一半機會換另一個),節奏型八分(大多)、四分、十六分(只在 5 級、♩ ≤ 100);小鼓在第 2、4 拍;
  每小節 35%(4 級)/ 45%(5 級)機會多一下小鼓(第 4 拍的反拍或第 4 個十六分、第 2 拍的第 4 個十六分、第 3 拍的反拍)。第 1 小節第 1 拍 40% 是 Crash。
- **大鼓**:兩拍一組的節奏格(`KICK_HALF`;前半一定有第 1 拍),同一段的下一小節每半 30% 換;5 級的權重比較偏切分。
- **過門**:前段最後一小節 1 拍 / 2 拍 / 整小節,後段 1 或 2 拍;每拍一格(`FILL`,第一拍一定從拍點開始),鼓從小鼓(或高音鼓)往下走,
  四個音以上的格子有時候分兩個鼓;有拍點的格子 35% 加大鼓。
- 每一小節手、腳都至少一個音(腳整小節空白會變成全休止符,不在白名單)。

## 3. RSL 聽力(`js/ear/gen.js`;STAGES.md S12、決定 6)

### 3.1 介面

- `genFill(spec, seed, grade)` → `{ kind:"fill", time, bars:1, bpm, cells, pool, spec(lines:1), measures, events, lenBeats, options, plays, countInBars, values, rests, notes, src }`
- `distractors(fill, n = options − 1, seed)` → 干擾選項(同格式,另加 `changed` = 改了第幾拍);`fillOptions(fill, seed)` → `{ options(洗牌), answer }`

- `spec` = `ear[g]`(也可以直接給 `ear[g].fill` / `ear[g].groove`);級數一定要給(Fill 的格子權重照級數)。

### 3.3 Fill 出題設計(練習設定)

- 一拍一格(`FILL_CELLS`):`4`、`8 8`、`16 16 16 16`、`8 16 16`、`16 16 8`、`16 8 16`(3 級起)、`8t3 ×3`、`8. 16` / `16 8.`(4 級起;6–8 級權重比 4、5 級低)、`16t6 ×6`(6 級起)、
  `r4`(有四分休止符的級數)、`r8 8`、`8 r8`、`r8 16 16`、`16 16 r8`(6 級起)、`r16 16 8`、`r16 16 16 16`、`8 r16 16`、`16 r16 8`(7 級起);
  格子裡每個時值 / 休止符都要在這一級的白名單裡。連音一組一拍、從拍點開始。
- **休止的比例**:7–8 級多了十六分休止符的格子,但休止格的權重調低,含休止的拍維持在 6 級的水準(約 16%;1000 題統計,gen-ear.mjs 檢查不超過 6 級的 1.15 倍)。
- 一小節:至少 4 個音、整拍休止最多一個、四拍不全一樣;每題至少一格用到這一級最該練的時值(Debut–1 八分、2 十六分、3 八分三連音、4–5 附點八分、6–8 十六分六連音)。
- **干擾選項**:每個只改一拍成這一級另一個合法的格子(音數相近的優先);整小節的擊打時間跟答案不同、彼此也不同
  (`4` 換 `8 r8` 這種聽起來一樣的不算);先找也合乎一小節規則的,找不到才放寬(NOTES.distractor)。

### 3.5 Groove 出題設計(練習設定)

- **鈸**(`G_CYM`):3 級以前只有 HH;4 級起 HH / Ride / 整段 Ride 碗 = 3 : 2.4 : 0.6(4 級)、3 : 2.2 : 0.5(5 級)、2.6 : 2.6 : 0.5(6–8 級)。

  | 節奏型 | 級數 | 備註 |

  | 八分 | 全部 | 可以開 HH |

## 4. 播放事件(`js/shared/kitevents.js`)

- `toEvents(spec, { bpm, dyn = "mf" })` → `[{ beat, piece, vel, m, grace?, accent?, ghost? }]`:RSL 整組鼓視奏、RSL 聽力、Trinity Playback(`chart.spec`、`phraseSpec`)共用,給 `player.play({ events })`。
  視奏分頁(`js/sight/app.js`)的 RSL 4–5 整組鼓與 Trinity Playback 看譜練習都用這一支(改速度時照新速度重算,裝飾音的提前量跟速度有關)。
- 音量(**練習設定**,EVENT_NOTES.velocity):pp .25 / p .4 / mp .55 / mf .7 / f .85 / ff 1.0(跟 `player.js` 的 `DYN_VEL` 一樣,gen-kit.mjs 核對);
  漸強漸弱從開始的力度直線變到結束位置的下一個力度記號(後面沒有就變一級;前面沒有力度記號就從 mf 算);sfz 1.0;重音 +0.2;幽靈音 ×0.4。
- **沒寫力度**(那個位置前面沒有力度記號,也沒給 `opts.dyn`)= 鼓件預設音量 `PIECE_VEL`(**練習設定**,EVENT_NOTES.pieceVel;各出題器的 notes 都帶 `pieceVel`):

  | 鼓件 | HH(閉)| 開 HH | 腳踩 HH | Ride | Ride 碗 | Crash | 小鼓 | cross stick | 大鼓 | 筒鼓(三個)|
  |---|---|---|---|---|---|---|---|---|---|---|
  | 音量 | .55 | .6 | .5 | .6 | .65 | .85 | .75 | .7 | .75 | .75 |

  鈸比鼓小聲、Crash 最大聲,律動聽起來才有層次。RSL 視奏、RSL 聽力(Fill / Groove)、Trinity Initial(沒有力度記號)都用這張表;重音、幽靈音、裝飾音照上面的規則算在表上的音量上。

- Flam / Drag:裝飾音照技巧模組(`js/tech/app.js` schedulePlay)在主音前 min(32 ms, 1/10 拍)(Drag 兩下),音量 = 那裡的力度 × 0.5,事件帶 `grace:true`;
